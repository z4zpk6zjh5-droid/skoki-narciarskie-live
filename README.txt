SKOKI NARCIARSKIE LIVE – PAKIET STARTOWY

Pliki:
- index.html – responsywna strona
- manifest.json – konfiguracja instalowalnej aplikacji PWA
- sw.js – podstawowy cache offline

WAŻNE:
To wersja startowa front-endu. Nie zawiera jeszcze prawdziwych wyników na żywo,
oficjalnego terminarza, prognoz ani powiadomień. Nie pokazuje fikcyjnych danych
jako prawdziwych. Przed uruchomieniem publicznym trzeba podłączyć legalne źródła
danych i zweryfikować ich warunki użycia.

Publikacja:
Wgraj zawartość folderu na darmowy hosting statyczny, np. GitHub Pages lub
Cloudflare Pages, po utworzeniu konta. Hosting i wymagania mogą się zmieniać;
przed publikacją sprawdź aktualne warunki dostawcy.
